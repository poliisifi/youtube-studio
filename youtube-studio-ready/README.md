# YouTube Studio — Premium Clone

Frontend React + Vite inspiré de YouTube Studio, prêt pour GitHub Pages.

## Déploiement GitHub Pages

1. Envoyez tous les fichiers de ce projet dans le dépôt `poliisifi/youtube-studio`.
2. Ouvrez **Settings → Pages** sur GitHub.
3. Dans **Build and deployment**, choisissez **GitHub Actions** comme source.
4. Faites un commit sur `main` ou relancez le workflow **Deploy YouTube Studio to GitHub Pages**.
5. Le site sera publié automatiquement.

Le projet utilise `base: /youtube-studio/` pendant GitHub Actions et fonctionne avec une navigation interne sans backend.
